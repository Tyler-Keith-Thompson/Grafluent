Critical path

Some tasks have to wait for others. How soon can the whole project be done, and which tasks can’t slip?

What it’s forThe earliest finish, and the tasks that set it

The critical path method schedules a project made of tasks that wait for each other. It finds the earliest day the whole project can finish. It also finds the tasks that set that day. A day lost on one of them is a day lost on the finish. The other tasks have some room to slip.

Reach for it to plan a build, an event, or any project with dependencies. It tells you which tasks to watch most closely.

Example: putting on a school play. Each task takes some days. An arrow means the task at its tail must be finished before the next can start. Tasks with no arrow between them can run at the same time.

The events come from lazy.kahn(). Each start day is worked out as they come. A finish passed on can only push a later task’s start back.

The ideaThe longest path sets the pace

The tasks and their arrows form a directed graph with no cycles, because a task can’t wait for itself. Take the tasks in a topological order, so everything a task waits for comes first. Give each task the earliest start it can have. That is the latest finish among the tasks it waits for. One pass in that order schedules everything. It takes time in proportion to the tasks plus the arrows.

The project’s length is the longest path through the graph, counting each task’s days. The tasks on that path are the critical path. Each one starts the moment the one before it ends.

Every other task has slack. A second pass, backwards from the end, finds it. The latest a task can start is the earliest start of any task after it, less its own days. Slack is the gap between that latest start and its earliest start.

In most graphs, finding a longest path is hard. Here it is easy, because without cycles there is no way to go round and round making a path longer. longestPath(weight:) on a DirectedAcyclicGraph runs the same pass over the order the graph already keeps. The weight of an arrow is the days of the task it leaves. So a path’s weight is the total of its tasks.

Where it breaksDurations are guesses, and people are limited

The critical path assumes every task takes exactly its estimate. Real tasks vary. A path with a little slack can turn critical when one of its tasks runs late. PERT treats each duration as a range and asks how likely the deadline is.

It also assumes unlimited hands. Say the same three people must build the set and make the costumes. Then those tasks can’t overlap. Scheduling with limited people or machines is a much harder problem.

If the arrows ever form a cycle, no order exists at all. DirectedAcyclicGraph refuses the edge that would close it. On a plain graph, findCycle() shows which tasks wait for each other.

In SwiftThe play above, in Grafluent

import AdjacencyListModule
import DirectedAcyclicGraphModule
import GraphProtocols
import Traversal

let days = [
    "Choose play": 2, "Cast actors": 3, "Build set": 6, "Print posters": 2, "Make costumes": 4,
    "Rehearse": 5, "Sell tickets": 4, "Dress rehearsal": 1, "Opening night": 0,
]
let comesBefore = [
    DirectedEdge(from: "Choose play", to: "Cast actors"), DirectedEdge(from: "Choose play", to: "Build set"),
    DirectedEdge(from: "Choose play", to: "Print posters"), DirectedEdge(from: "Cast actors", to: "Make costumes"),
    DirectedEdge(from: "Cast actors", to: "Rehearse"), DirectedEdge(from: "Build set", to: "Dress rehearsal"),
    DirectedEdge(from: "Make costumes", to: "Dress rehearsal"), DirectedEdge(from: "Rehearse", to: "Dress rehearsal"),
    DirectedEdge(from: "Print posters", to: "Sell tickets"), DirectedEdge(from: "Sell tickets", to: "Opening night"),
    DirectedEdge(from: "Dress rehearsal", to: "Opening night"),
]

let play = DirectedAcyclicGraph<AdjacencyList<String>> {
    for step in comesBefore { step }
}!

let events = Array(play.lazy.kahn())  // 29 events

let critical = play.longestPath { days[play.edges[$0].source]! }!
let tasks = critical.vertices  // ["Choose play", "Cast actors", "Rehearse", "Dress rehearsal", "Opening night"]
let length = critical.weight { days[play.edges[$0].source]! }  // 11

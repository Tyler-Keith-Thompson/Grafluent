Graph coloring

Say itKUH-ler-ing; the fewest colours is thekroh-MAT-iknumber

What’s the fewest exam slots so that no student has two exams at once?

Example: eight exams, with a line between any two that share a student.

A line means some student sits both exams, so they need different slots. The number in each exam is its slot. Click two exams to add a clash; click a line to remove it.

In SwiftThe timetable above, in Grafluent

import AdjacencyListModule
import BipartiteGraphs
import ColoringModule
import GraphProtocols

let courses = ["Art", "Biology", "Chemistry", "Drama", "English", "French", "Geography", "History"]
let clashes = [
    ("Art", "Drama"),
    ("Art", "French"),
    ("Art", "History"),
    ("Chemistry", "Biology"),
    ("Chemistry", "French"),
    ("Chemistry", "History"),
    ("English", "Biology"),
    ("English", "Drama"),
    ("English", "History"),
    ("Geography", "Biology"),
    ("Geography", "Drama"),
    ("Geography", "French"),
]

let exams = UndirectedAdjacencyList<String> {
    for course in courses { course }
    for (a, b) in clashes { UndirectedEdge(a, b) }
}

let order = courses

let greedy = exams.greedyColoring(order: order)  // 4 colours: {Art, Biology} {Chemistry, Drama} {English, French} {Geography, History}

let fewest = exams.chromaticNumber()  // 2
let best = exams.minimumColoring()  // 2 colours: {Art, Chemistry, English, Geography} {Biology, Drama, French, History}

The ideaA colour per time slot

Give each exam a colour, one colour per time slot, so that no two exams joined by a line share a colour. Greedy coloring goes through the exams one by one and gives each the first colour its neighbours aren’t using. It’s quick and usually good. Finding the true minimum, the chromatic number, means a search that can be slow, and the page lets you compare the two.

Where it breaksA bad order

Greedy’s answer depends on the order it goes in. Here, in alphabetical order, it needs four slots, twice as many as the two that are enough. The exams fall into two groups, and each exam clashes with every exam in the other group except one partner. Alphabetical order keeps reaching a partner pair together, and gives the pair a slot of its own. Choosing the most constrained exam next (DSATUR) finds two slots: on a two-sided graph like this one it always does.

Minimum-cost flow

Two warehouses, four shops, roads that carry only so much and cost so much per crate. What’s the cheapest way to stock every shop?

What it’s forThe cheapest plan that meets every demand

Some places have goods to send, and some places want them. Each road can carry only so much, and each unit costs something to send. A minimum-cost flow is the cheapest way to move everything so that every place gets what it wants.

Reach for it to plan deliveries, to route traffic or data at the least cost, or to schedule work across machines. Shortest paths, maximum flow and the assignment problem are all special cases of it.

The simpler methods are faster when they fit. A minimum-cost flow is the one to use when limits and costs both matter.

Each step is a fresh minimumCostFlow call with one more shop open: the network simplex itself runs to the optimum in one go. Labels are crates sent / crates allowed, then the cost per crate.

The ideaSupplies, demands, capacities and costs

Each place gets a supply. A positive supply sends that much more than it receives. A negative one is a demand. Each road gets a capacity and a cost per unit. The answer is the flow that meets every supply and demand, stays within every capacity, and costs least in total.

The warehouses here should send up to their stock, not exactly that much. A standard trick handles this. One made-up place, Stock, supplies everything the shops want. A free road runs from Stock to each warehouse, as wide as that warehouse’s stock. Each shop’s demand is its order, and the solver decides which warehouse fills it.

The cheapest plan isn’t built greedily. Ashby is cheapest to stock through the hub, until Colby opens. Colby’s only cheap road starts at the hub, and the hub can take in only 6 crates a day. So the cheapest plan for three shops moves Ashby’s crates to the dearer direct road. That frees the hub for Colby.

minimumCostFlow runs the network simplex. It keeps a tree of roads whose flows are free to change. Again and again it adds a road that would lower the cost, and sends flow round the loop that road closes. It stops when no road would help. The answer comes with a price at every place, called a potential. No road with room left costs less than the difference in price across it. That proves no better plan exists.

Where it breaksWhole crates, straight costs

Costs here grow in a straight line, so two crates cost twice as much as one. Real deliveries often have a fixed cost per truck, discounts for bulk, or a choice of whether to open a warehouse at all. Those make the problem much harder. They need integer programming, often with a flow problem like this one inside. When every supply, demand and capacity is a whole number, the network simplex always finds a plan in whole crates. That suits goods that don’t split.

If the shops want more than the roads can carry, no plan exists and the call returns nil. To send as much as possible and then pay least for it, use minimumCostMaximumFlow.

import AdjacencyListModule
import Flows
import GraphProtocols

let roads: [(road: DirectedEdge<String>, crates: Int, cost: Int)] = [
    (DirectedEdge(from: "Stock", to: "North"), 6, 0),
    (DirectedEdge(from: "Stock", to: "South"), 5, 0),
    (DirectedEdge(from: "North", to: "Ashby"), 4, 3),
    (DirectedEdge(from: "North", to: "Barton"), 3, 4),
    (DirectedEdge(from: "North", to: "Hub"), 3, 1),
    (DirectedEdge(from: "South", to: "Colby"), 2, 5),
    (DirectedEdge(from: "South", to: "Denton"), 3, 2),
    (DirectedEdge(from: "South", to: "Hub"), 3, 1),
    (DirectedEdge(from: "Hub", to: "Ashby"), 3, 1),
    (DirectedEdge(from: "Hub", to: "Barton"), 3, 1),
    (DirectedEdge(from: "Hub", to: "Colby"), 4, 2),
    (DirectedEdge(from: "Hub", to: "Denton"), 2, 3),
]
let demand = ["Ashby": 3, "Barton": 2, "Colby": 4, "Denton": 2]

let deliveries = AdjacencyList<String> {
    for r in roads { r.road }
}
let crates = Dictionary(uniqueKeysWithValues: roads.map { ($0.road, $0.crates) })
let cost = Dictionary(uniqueKeysWithValues: roads.map { ($0.road, $0.cost) })

let open = []

let wanted = open.reduce(0) { $0 + demand[$1]! }
let plan = deliveries.minimumCostFlow(
    supply: { place in place == "Stock" ? wanted : open.contains(place) ? -demand[place]! : 0 },
    capacity: { crates[deliveries.edges[$0]]! },
    cost: { cost[deliveries.edges[$0]]! })
let total = plan?.cost  // 0
let shipped = plan?.value  // 0

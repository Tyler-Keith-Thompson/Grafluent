Covers and dominating sets

Where should the cameras go so every street is watched, and the fire stations so every corner is close to one?

What it’s forThe fewest places that reach everything

A vertex cover is a set of vertices that touches every line. A camera on a corner sees every street that meets there, so cameras that watch every street form a vertex cover. A dominating set is a set of vertices that every other vertex sits next to. A fire station serves its own corner and every corner one street away, so stations that serve the whole town form a dominating set.

Reach for these when you must place as few things as possible and still reach everything. Examples are guards and sensors, shops and depots, or monitors on a computer network.

The exact searches give the true fewest. The approximations are fast and come with a promise of how far off they can be. In the table, n is the number of corners, m the number of streets and Δ the most streets at any one corner.

The ideaEasy to check, hard to make small

Checking a plan is quick. isVertexCover(_:) looks at every street once. isDominatingSet(_:) looks at every corner and its neighbours. Finding the smallest plan is much harder. Both problems are NP-hard, so minimumVertexCover() and minimumDominatingSet() search. They use rules that settle easy parts first. Take a corner on a dead end. Its one street is best watched from the other end. A town this size takes a moment. For large, tangled networks the time can grow exponentially.

Many plans can be equally small. minimumVertexCover() returns whichever its search finds first. The lexicographicallyFirst forms pick by a rule instead. They return the smallest plan whose corners come earliest in the list. The answer then depends only on the town and the order of its corners. That matters when a result is saved, compared or tested.

When the exact search is too slow, the approximations are quick. approximateMinimumVertexCover() goes through the streets. For each street still unwatched, it puts a camera at an end. That never uses more than twice as many as needed. approximateMinimumDominatingSet() is the greedy plan in the second lab, which is Chvátal’s. It always picks the corner that serves the most corners not yet served.

Where it breaksSmall isn’t always best

The fewest cameras may still be the wrong plan if corners differ in cost. A camera on a quiet lane is cheaper than one on a busy junction. Both approximations take a weight: for that.

A dominating set also says nothing about distance beyond one street, or about how many corners each station serves. A station on a corner with eight streets may be swamped while another serves one. Those are different problems, such as facility location and the k-centre problem.

Covers and independent sets are two sides of one coin. The corners without cameras never share a street. So a smallest cover is what is left after a largest independent set. On a two-sided graph, such as streets that only join north-side corners to south-side ones, Kőnig’s theorem makes the cover as easy as a matching.

In SwiftThe town above, in Grafluent

import AdjacencyListModule
import Covering
import GraphProtocols

let townStreets = [
    UndirectedEdge("Church", "Mill"), UndirectedEdge("Mill", "Park"), UndirectedEdge("Park", "Dock"),
    UndirectedEdge("School", "Square"), UndirectedEdge("Square", "Market"), UndirectedEdge("Market", "Pier"),
    UndirectedEdge("Farm", "Bakery"), UndirectedEdge("Bakery", "Library"), UndirectedEdge("Library", "Station"),
    UndirectedEdge("Church", "School"), UndirectedEdge("School", "Farm"), UndirectedEdge("Mill", "Square"),
    UndirectedEdge("Square", "Bakery"), UndirectedEdge("Park", "Market"), UndirectedEdge("Market", "Library"),
    UndirectedEdge("Dock", "Pier"), UndirectedEdge("Pier", "Station"), UndirectedEdge("Square", "Library"),
    UndirectedEdge("Mill", "School"),
]

let crossroads = UndirectedAdjacencyList<String> {
    for street in townStreets { street }
}

let chosen = ["Square", "Market"]

let fewest = crossroads.minimumVertexCover().count  // 7
let first = crossroads.lexicographicallyFirstMinimumVertexCover()  // ["Church", "Mill", "Park", "Square", "Pier", "Farm", "Library"]
let quick = crossroads.approximateMinimumVertexCover()  // ["Church", "Mill", "Park", "Dock", "School", "Square", "Market", "Pier", "Farm", "Bakery", "Library"]
let allSeen = crossroads.isVertexCover(chosen)  // false

import AdjacencyListModule
import Covering
import GraphProtocols

let townStreets = [
    UndirectedEdge("Church", "Mill"), UndirectedEdge("Mill", "Park"), UndirectedEdge("Park", "Dock"),
    UndirectedEdge("School", "Square"), UndirectedEdge("Square", "Market"), UndirectedEdge("Market", "Pier"),
    UndirectedEdge("Farm", "Bakery"), UndirectedEdge("Bakery", "Library"), UndirectedEdge("Library", "Station"),
    UndirectedEdge("Church", "School"), UndirectedEdge("School", "Farm"), UndirectedEdge("Mill", "Square"),
    UndirectedEdge("Square", "Bakery"), UndirectedEdge("Park", "Market"), UndirectedEdge("Market", "Library"),
    UndirectedEdge("Dock", "Pier"), UndirectedEdge("Pier", "Station"), UndirectedEdge("Square", "Library"),
    UndirectedEdge("Mill", "School"),
]

let crossroads = UndirectedAdjacencyList<String> {
    for street in townStreets { street }
}

let chosen = ["Dock", "School", "Square", "Pier"]

let fewest = crossroads.minimumDominatingSet().count  // 3
let first = crossroads.lexicographicallyFirstMinimumDominatingSet()  // ["Mill", "Pier", "Bakery"]
let quick = crossroads.approximateMinimumDominatingSet()  // ["Dock", "School", "Square", "Pier"]
let allReached = crossroads.isDominatingSet(chosen)  // true

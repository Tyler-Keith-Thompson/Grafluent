Girvan–Newman

If you keep cutting the link that the most shortest paths cross, what groups are left?

What it’s forSplitting a network, coarse to fine

Girvan–Newman finds communities by cutting. It takes out the link that the most shortest paths cross, again and again, until the network falls into pieces. You get every split along the way, from two groups down to everyone alone.

Reach for it on a small network when you want the whole family of splits, or a reason you can explain for each cut. On a large network it is far too slow.

Girvan–Newman is the easiest to reason about and the slowest. Louvain is the usual choice once a network has more than a few hundred people.

Example: twelve friends from a band, a climbing gym and a book club. A line joins each pair who hang out. A few friendships cross between the groups.

Each step is one removal. girvanNewmanCommunities() reports only the splits. To show the removals in between, the page makes them itself and recomputes edgeBetweennessCentrality each time.

The ideaLinks between groups carry the traffic

Inside a close group there are many ways between any two people. So the shortest paths spread over many links. Between groups there are only a few links, and every shortest path from one group to another has to use one of them. So those links have the highest edge betweenness.

Girvan and Newman’s method takes out the link with the highest betweenness. Then it recomputes every score, and repeats. Recomputing matters. Once one link between two groups is gone, the paths it carried move to the others. Those become the busiest next.

Each time the network falls into more pieces, you get a finer split. Run to the end and every person is alone. The result is a whole hierarchy of splits, coarsest first.

Which level is the answer? A common choice is the one with the highest modularity. Modularity is the share of links inside groups, minus the share you’d expect if links were placed at random. girvanNewmanCommunities() is a lazy sequence of the splits. You can stop at the first with as many groups as you want, or take the best by modularity(of:).

Where it breaksSlow, and it only cuts

Every removal recomputes betweenness for the piece it came from. That costs a search from every person in it. It is fine for a few hundred people, but the whole sequence is O(m²n). For large networks, Louvain or Leiden find high-modularity groups in a few passes.

It also only ever cuts. A person who belongs to two groups ends up in one of them. A network with no clear groups still gets split, all the way down. So check that the modularity is high before you trust the groups.

import AdjacencyListModule
import Centrality
import CommunityDetection
import Connectivity
import GraphProtocols

let hangOut = [
    UndirectedEdge("Abe", "Bea"), UndirectedEdge("Abe", "Cam"), UndirectedEdge("Bea", "Cam"),
    UndirectedEdge("Bea", "Dan"), UndirectedEdge("Cam", "Dan"),
    UndirectedEdge("Ela", "Fox"), UndirectedEdge("Ela", "Gil"), UndirectedEdge("Fox", "Gil"),
    UndirectedEdge("Fox", "Hal"), UndirectedEdge("Gil", "Hal"),
    UndirectedEdge("Ian", "Jo"), UndirectedEdge("Ian", "Kai"), UndirectedEdge("Jo", "Kai"),
    UndirectedEdge("Jo", "Lu"), UndirectedEdge("Kai", "Lu"),
    UndirectedEdge("Dan", "Ela"), UndirectedEdge("Hal", "Ian"), UndirectedEdge("Cam", "Kai"),
]

let crowd = UndirectedAdjacencyList<String> {
    for pair in hangOut { pair }
}

let partitions = Array(crowd.girvanNewmanCommunities())  // 11 partitions
let best = partitions.max { crowd.modularity(of: $0) < crowd.modularity(of: $1) }!  // [["Abe", "Bea", "Cam", "Dan"], ["Ela", "Fox", "Gil", "Hal"], ["Ian", "Jo", "Kai", "Lu"]]

var left = hangOut
var removed: [UndirectedEdge<String>] = []
while !left.isEmpty {
    let now = UndirectedAdjacencyList<String> {
        for person in crowd.vertices { person }
        for pair in left { pair }
    }
    let busy = now.edgeBetweennessCentrality(normalized: false)
    let busiest = now.edges.indices.max { busy.score(ofEdgeAt: $0) < busy.score(ofEdgeAt: $1) }!
    removed.append(left.remove(at: busiest))
}

let gone = removed.prefix(0)

let left = UndirectedAdjacencyList<String> {
    for person in crowd.vertices { person }
    for pair in hangOut where !gone.contains(pair) { pair }
}
let busy = left.edgeBetweennessCentrality(normalized: false)
let groups = left.connectedComponents()  // [["Abe", "Bea", "Cam", "Dan", "Ela", "Fox", "Gil", "Hal", "Ian", "Jo", "Kai", "Lu"]]

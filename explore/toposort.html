Topological sort

In what order can you do tasks that depend on each other?

Example: getting dressed. Socks go on before shoes, a shirt before a tie, and trousers before a belt. Add a new rule and watch the order update.

An arrow a → b means a goes on before b. Click one item, then another, to add a rule. Click an arrow to remove it.

What it’s forAn order that keeps every rule

A topological sort puts tasks in an order where each one comes after everything it depends on. Reach for it to order the steps of a build, the courses in a degree, or the cells of a spreadsheet. If the rules go round in a circle, no order exists, and the sort tells you so.

The ideaDo whatever has nothing left to wait for

Draw an arrow from each task to anything that has to wait for it. A valid order lists every task before everything its arrows point to.

Kahn’s algorithm is one way to find it. Take any task with no arrows coming in. Write it down and remove it. That may free up other tasks. Each round frees a wave of tasks that could all happen at the same time.

Grafluent’s topologicalSort() uses the other classic way, a depth-first search. It lists each task once everything after it is finished. Then it reads the list backwards.

All three take time in proportion to the tasks and rules. In the table, n is the number of tasks and m the number of rules.

Where it breaksRules that go round in a circle

Add “shoes before socks”, and there is no valid order at all. The rules go round in a circle. topologicalSort() returns nil. findCycle() hands back the circle, so you can see which rule to drop.

In SwiftThe wardrobe above, in Grafluent

import AdjacencyListModule
import GraphProtocols
import Traversal

let clothes = ["Underwear", "Socks", "Shirt", "Watch", "Trousers", "Tie", "Shoes", "Belt", "Jacket"]
let rules = [
    ("Underwear", "Trousers"),
    ("Underwear", "Shoes"),
    ("Trousers", "Shoes"),
    ("Trousers", "Belt"),
    ("Socks", "Shoes"),
    ("Shirt", "Belt"),
    ("Shirt", "Tie"),
    ("Tie", "Jacket"),
    ("Belt", "Jacket"),
]

let wardrobe = AdjacencyList<String> {
    for item in clothes { item }
    for (first, then) in rules { DirectedEdge(from: first, to: then) }
}
let events = Array(wardrobe.lazy.depthFirstSearch())  // 27 events
let order = wardrobe.topologicalSort()  // ["Watch", "Shirt", "Tie", "Socks", "Underwear", "Trousers", "Belt", "Jacket", "Shoes"]
let waves = wardrobe.topologicalGenerations()  // 4 waves
let cycle = wardrobe.findCycle().map(Array.init)  // nil

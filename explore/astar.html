A* search

If you only care about one destination, can you skip the rest of town?

What it’s forThe quickest route to one goal

A* finds the quickest route from a start to one goal. It needs a guess of how far each place is from the goal. With a good guess, it looks at far fewer places than Dijkstra’s algorithm does.

Reach for it on maps, game levels and puzzles, where you know roughly where the goal is. Straight-line distance is the usual guess. When you need routes to every place, use Dijkstra instead.

A* gives the same answer as Dijkstra and usually does much less work. It needs a guess that never says a place is further than it is. In the table, n is the number of places and m the number of streets.

The ideaDijkstra with a sense of direction

Dijkstra ranks each place by the distance walked so far. A* adds a guess of the distance still to go. Here the guess is the straight-line distance to the café. Places that point the right way get settled first. So the search reaches the café after exploring only part of the grid.

Switch between A* and Dijkstra and watch the explored region. Dijkstra’s spreads evenly in every direction, like a circle, until the edges of the grid cut it off. A*’s is a narrow teardrop pointed at the café.

The straight line is a good guess because no walk can beat it. Walls only make the walk longer. A guess that never overestimates is called admissible. With one, A* still finds the shortest route. It just skips blocks that point away from the café.

A guess like this is called a heuristic. It goes in heuristic:, a closure from a block to a number. Pass one that always returns zero, and A* is exactly Dijkstra.

Where it breaksA guess that says “far” about somewhere close

The guess must never overestimate. If it says “far” about a place that is actually close, A* can settle on a longer route. Press Overestimate ×3 to triple every guess. A* now rushes straight at the café and hugs the wall. It settles for a walk longer than the shortest.

With some walls it also settles a block too early, and later finds a shorter way to it. Then the block is opened again, shown as a red dot on the timeline. Reopening repairs the blocks it reaches. But once the café itself is settled, the search is over.

Grafluent doesn’t check the guess, because it can’t know the true distances in advance. Some programs overestimate on purpose. They settle fewer blocks and accept a route that may be a little longer.

In SwiftThe city grid, in Grafluent

import AdjacencyListModule
import GraphProtocols
import ShortestPaths

/// A block of the city, by column and row.
struct Block: Hashable {
    var column: Int
    var row: Int

    /// The straight-line distance to `other`, in blocks.
    func distance(to other: Block) -> Double {
        let dx = Double(column - other.column), dy = Double(row - other.row)
        return (dx * dx + dy * dy).squareRoot()
    }

    /// The blocks one step east, south-east, south and south-west: each street once.
    var nextBlocks: [Block] {
        [(1, 0), (1, 1), (0, 1), (-1, 1)].map { Block(column: column + $0.0, row: row + $0.1) }
    }
}

let home = Block(column: 3, row: 4)
let café = Block(column: 10, row: 4)
let walls: Set<Block> = [
    Block(column: 6, row: 3),
    Block(column: 6, row: 5),
    Block(column: 7, row: 3),
    Block(column: 7, row: 4),
    Block(column: 7, row: 5),
]
let overestimate = 1.0

let isOpen = { (b: Block) in (0 ..< 13).contains(b.column) && (0 ..< 9).contains(b.row) && !walls.contains(b) }
let city = UndirectedAdjacencyList<Block> {
    for column in 0 ..< 13 {
        for row in 0 ..< 9 {
            let a = Block(column: column, row: row)
            if isOpen(a) {
                a
                // A diagonal step needs both blocks beside it open: no cutting corners.
                for b in a.nextBlocks {
                    if isOpen(b) && isOpen(Block(column: a.column, row: b.row)) && isOpen(Block(column: b.column, row: a.row)) {
                        UndirectedEdge(a, b)
                    }
                }
            }
        }
    }
}

let events = Array(city.lazy.aStar(from: home, to: café) { street in
    city.edges[street].u.distance(to: city.edges[street].v)
} heuristic: { block in
    overestimate * block.distance(to: café)
})  // 351 events

var dijkstra: [DijkstraSearchEvent<Block, DirectedView<UndirectedAdjacencyList<Block>>.Edges.Index, Double>] = []
for event in city.lazy.dijkstra(from: home, weight: { city.edges[$0].u.distance(to: city.edges[$0].v) }) {
    dijkstra.append(event)
    if case .examine(café, _) = event { break }  // Stop once the café is settled.
}

let route = city.aStarShortestPath(from: home, to: café) { street in
    city.edges[street].u.distance(to: city.edges[street].v)
} heuristic: { block in
    overestimate * block.distance(to: café)
}
let walked = route?.distance  // 8.66

Force-directed layout

Say itFROOK-ter-mun RINE-gold/ˈfruːktərmən ˈraɪnɡoʊld/

How do you draw a graph so its shape is easy to see?

Example: a tangle of twenty vertices that untangles itself as you watch. Drag any vertex and the rest respond.

import AdjacencyListModule
import GraphDrawing
import GraphProtocols
import NamedGraphs

let families: [(name: String, graph: UndirectedAdjacencyList<Int>)] = [
    ("Dodecahedron", .dodecahedral()),
    ("Petersen graph", .petersen()),
    ("Cube", .hypercube(dimension: 3)),
    ("Grid", .grid(dimensions: [4, 5])),
    ("Tree", .balancedTree(branchingFactor: 2, height: 3)),
    ("Barbell", .barbell(cliqueVertexCount: 5, pathVertexCount: 3)),
]

let choice = 0  // Dodecahedron

var layout = FruchtermanReingoldLayout(families[choice].graph, iterations: 200)

var frames = [(drawing: layout.drawing, temperature: layout.temperature)]
while !layout.isFinished {
    layout.step()
    frames.append((layout.drawing, layout.temperature))
}

var positions = drawing.positions
positions[drawing.vertices.firstIndex(of: vertex)!] = point
let moved = Drawing(vertices: drawing.vertices, positions: positions)
let restarted = FruchtermanReingoldLayout(families[choice].graph, initial: moved, iterations: 80)

The ideaSprings and magnets

Treat edges as springs that pull their ends together, and every pair of vertices as magnets that push apart. Let the system settle and connected groups cluster, while unrelated parts drift away from each other. Fruchterman–Reingold cools the motion over time so the picture comes to rest: each step may move a vertex at most the current temperature, and the temperature falls with every step.

Where it breaksHairballs

Large graphs turn into a hairball no matter how they’re drawn. Past a few hundred vertices, it is better to find communities first and draw those. The forces also only see edges, never what the vertices mean: a drawing can look like it has clusters that aren’t really there.

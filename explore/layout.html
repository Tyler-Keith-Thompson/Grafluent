Force-directed layout

Say itFROOK-ter-mun RINE-gold/ˈfruːktərmən ˈraɪnɡoʊld/

How do you draw a graph so its shape is easy to see?

What it’s forA picture of a graph’s shape

A graph is only a list of links, so it has no picture of its own. A force-directed layout gives every vertex a place. Linked vertices end up close, and the rest spread out. Groups, symmetries and long chains then show at a glance.

Reach for it when you have a small or medium graph and no better idea of how it should look. It knows nothing about direction or rank, only about links.

Fruchterman–Reingold is the general-purpose choice. It works on anything and needs no tuning, but it is slow on big graphs and gives a new picture for each new start. In the table, n is the number of vertices and m the number of edges.

The ideaSprings and magnets

Treat each edge as a spring that pulls its ends together. Treat every pair of vertices as magnets that push apart. Let the system settle. Connected groups cluster, and unrelated parts drift away from each other.

Fruchterman–Reingold cools the motion over time, so the picture comes to rest. In each step a vertex may move at most the current temperature, and the temperature falls with every step.

Where it breaksHairballs

Large graphs turn into a hairball however they are drawn. Past a few hundred vertices, it is better to find communities first and draw those. The forces also see only edges, never what the vertices mean. A drawing can look like it has clusters that aren’t really there.

import AdjacencyListModule
import GraphDrawing
import GraphProtocols
import NamedGraphs
import RandomGraphs

let families: [(name: String, graph: UndirectedAdjacencyList<Int>)] = [
    ("Dodecahedron", .dodecahedral()),
    ("Petersen graph", .petersen()),
    ("Cube", .hypercube(dimension: 3)),
    ("Grid", .grid(dimensions: [4, 5])),
    ("Tree", .balancedTree(branchingFactor: 2, height: 3)),
    ("Barbell", .barbell(cliqueVertexCount: 5, pathVertexCount: 3)),
]

let choice = 0  // Dodecahedron
let seed: UInt64 = 1

var generator = Xoshiro256StarStar(seed: seed)
var layout = FruchtermanReingoldLayout(families[choice].graph, iterations: 200, using: &generator)

var frames = [(drawing: layout.drawing, temperature: layout.temperature)]
while !layout.isFinished {
    layout.step()
    frames.append((layout.drawing, layout.temperature))
}

var positions = drawing.positions
positions[drawing.vertices.firstIndex(of: vertex)!] = point
let moved = Drawing(vertices: drawing.vertices, positions: positions)
let restarted = FruchtermanReingoldLayout(families[choice].graph, initial: moved, iterations: 80)

Feedback sets

Nine packages import each other in four loops, so nothing can be built first. What is the smallest number of imports to cut, and which?

What it’s forBreaking every loop at the least cost

A feedback arc set is a set of arrows whose removal leaves no directed cycle; a feedback vertex set does the same with vertices. The minimum ones are the cheapest way to make a graph acyclic: the fewest imports to untangle, the fewest tables to drop from a chain of foreign keys, the fewest matches to discount when ranking teams from who beat whom, or where to put the backward edges when drawing a graph in layers.

Both minimum problems are NP-hard, so the exact answers take time exponential in the number of vertices and are for small graphs: a dependency graph of a few dozen packages, not a web crawl. For large graphs there is a fast heuristic that is usually close.

Take the exact set when the graph is small and the count matters; take the heuristic otherwise. A condensation keeps the loops and works around them.

Example: nine packages whose imports form four loops: tests that import the app and the app that imports its tests, a cache behind an auth package behind a database behind the cache, and a logger that imports the core that imports it, with a detour through the network package.

The ideaOrder the vertices, then count the arrows pointing backward

Write the vertices in a line. Every arrow then points forward or backward, and the backward ones are a feedback arc set: remove them and every remaining arrow points forward, so no cycle can close. Every feedback arc set arises this way from some order, so the minimum one is the order with the fewest backward arrows. minimumFeedbackArcSet() finds that order by dynamic programming over subsets of vertices: the best order of a subset ends with the vertex whose arrows into the rest cost least, after the best order of the rest. Each subset is one entry in a table with 2ⁿ rows, which is why the search stops at 28 vertices. The weighted form adds up weights instead of counting, and a self-loop is always in the set, since no order can point it forward.

minimumFeedbackVertexSet() fills a table of the same size with a yes or no: a subset of vertices induces an acyclic subgraph when one of its vertices has no arrow coming in from the subset and the rest is acyclic, peeled one source at a time. The largest acyclic subset is the complement of the answer; on an undirected graph the peeling takes vertices with at most one neighbour left and finds the fewest vertices leaving a forest. feedbackArcSet() is Eades, Lin and Smyth’s heuristic: it builds an order greedily, placing sinks at the end and sources at the start and otherwise the vertex with the most arrows out relative to in, and takes the backward arrows of that order.

Where it breaksThe table doubles with every vertex

Thirty vertices would need a table of a billion rows, so the exact searches stop at 28 and 32 and trap beyond. On a bigger graph, condense it first: only the strongly connected pieces hold cycles, and each piece can be solved on its own if it is small enough. The heuristic has no such limit but no promise either; on this example it matches the minimum, and on others it can take a few more arrows than needed. And when several minimum sets exist, which arrows the exact search returns is unspecified: the vertices it returns are the set that lists first.

import AdjacencyListModule
import Cycles
import GraphProtocols
import Traversal

/// Nine packages and who depends on whom: an arrow from a package to one it imports.
let packages = ["App", "Test", "UI", "Auth", "Net", "Core", "Log", "DB", "Cache"]
let dependsOn: [(String, String)] = [
    ("App", "UI"), ("App", "Auth"), ("App", "Test"), ("Test", "App"), ("UI", "Core"), ("UI", "Net"), ("Net", "Core"),
    ("Core", "Log"), ("Log", "Core"), ("Log", "Net"), ("Auth", "DB"), ("DB", "Cache"), ("Cache", "Auth"), ("Cache", "Core"),
]
let dependencies = AdjacencyList<String> {
    for package in packages { package }
    for (from, to) in dependsOn { DirectedEdge(from: from, to: to) }
}

let loops = Array(dependencies.simpleCycles()).count  // 4
let cuts = dependencies.minimumFeedbackArcSet()  // [3, 7, 10]
let cheap = dependencies.feedbackArcSet()  // [3, 7, 12]
let culprits = dependencies.minimumFeedbackVertexSet()  // ["App", "Auth", "Core"]

let count = 0

let removed = Set(cuts.prefix(count))
let trimmed = AdjacencyList<String> {
    for package in packages { package }
    for position in dependencies.edges.indices where !removed.contains(position) { dependencies.edges[position] }
}
let loops = Array(trimmed.simpleCycles()).count  // 4
let order = trimmed.topologicalSort()  // nil

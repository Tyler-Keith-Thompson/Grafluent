Cycle bases

A park has paths that loop in many ways. What is the smallest set of loops that explains every other?

What it’s forA few loops that make every loop

Add two loops that share a stretch of path, and the shared stretch cancels: you get the loop around both. So loops combine. A cycle basis is a small set of loops from which every loop in the network can be built this way. A network with n places, m paths and one connected piece needs exactly m − n + 1 of them.

Reach for a cycle basis to find the rings in a molecule, the independent loops in an electrical circuit, or the faces of a map drawn from its roads. A minimum basis uses the shortest loops, which is usually the one you want to look at.

A fundamental basis is nearly free and always valid. The minimum basis costs more but reads like the faces of a map.

The ideaA spanning tree, then one more path at a time

Take any spanning tree of the network. It reaches every place and has no loop. Each path left out of the tree closes exactly one loop with it. Those loops are a fundamental basis. They are independent, because each has a path no other has, and there are m − n + 1 of them. cycleBasis() uses the breadth-first tree from the first place.

A fundamental basis can be ungainly. The loop a far-off path closes may wander across the whole tree. De Pina’s method finds a minimum basis instead. It keeps one marker set per dimension and, for each in turn, finds the shortest loop that crosses that marker set an odd number of times. The shortest such loop is found by searching two copies of the network, one for “crossed an even number of times so far” and one for “odd”. Then every later marker set is adjusted so it stays independent of the loops already chosen. minimumCycleBasis() is that method, and minimumCycleBasis(weight:) weighs the paths.

In the park the minimum basis is the four small loops: two triangles and two squares, 14 paths in all. The fundamental basis from the Gate has the same number of loops, but three of them go the long way round, and together they use 23 paths.

Where it breaksLoops are not faces

A minimum basis is not unique when loops tie in length, and it need not be the faces of any drawing. Give the Kiosk–Bridge path 90 metres in the lab, and the lightest basis swaps one square for the loop around both squares, because that loop avoids the long path. Weights must be positive. A path of weight zero would let a loop cost nothing, and the shortest loop through it would no longer be simple.

The minimum basis takes time that grows with m² n in the worst case, so it is for networks of thousands of paths, not millions. The fundamental basis takes time in step with the network.

In SwiftThe park, in Grafluent

import AdjacencyListModule
import Cycles
import GraphProtocols
import Walks

let footpaths = [
    UndirectedEdge("Gate", "Pond"), UndirectedEdge("Pond", "Oak"), UndirectedEdge("Oak", "Gate"),
    UndirectedEdge("Oak", "Kiosk"), UndirectedEdge("Kiosk", "Bridge"), UndirectedEdge("Bridge", "Pond"),
    UndirectedEdge("Kiosk", "Lawn"), UndirectedEdge("Lawn", "Fountain"), UndirectedEdge("Fountain", "Bridge"),
    UndirectedEdge("Lawn", "Shed"), UndirectedEdge("Shed", "Fountain"),
]

let commons = UndirectedAdjacencyList<String> {
    for path in footpaths { path }
}

let minimum = commons.minimumCycleBasis()  // [[Gate, Pond, Oak], [Lawn, Fountain, Shed], [Pond, Oak, Kiosk, Bridge], [Kiosk, Bridge, Fountain, Lawn]]
let length = minimum.reduce(0) { $0 + $1.edges.count }  // 14

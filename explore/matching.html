Bipartite matching

How do you fill as many jobs as possible when each applicant only fits some of them?

Example: five applicants, five jobs, and a line for each job an applicant can do. The vertices fall into two sides, and every line crosses between them. A graph like that is bipartite.

What it’s forAs many pairs as possible

A matching pairs things up so that nothing is in two pairs. A maximum matching has as many pairs as possible. Reach for it to give workers jobs, students places, or tasks machines, whenever each one fits only some of the other side.

Hopcroft–Karp is the fastest when all you count is pairs. When some pairs are better than others, use a weighted method. In the table, n is the number of vertices and m the number of lines.

The ideaChains of swaps

Start by pairing people up any way that works. When someone is left out, look for a chain. They take a job held by someone who can move to another job. That person frees up another job, and so on, until the chain ends at an empty job. Swapping along the chain fills one more job, and nobody loses theirs.

When no chain exists, the matching is as large as it can be. Hopcroft–Karp finds many chains at once, and that makes it fast.

Hall’s theorem says when everyone can be placed. Every group of applicants must fit, between them, at least as many jobs as there are people in the group. Two people who can only drive, and one driving job, break that rule.

Kőnig’s theorem links matchings to covers. In a bipartite graph, the most pairs equals the fewest vertices that touch every line.

Where it breaksWhen some pairings are better

A matching only counts pairs. If a good barista is a poor cashier, it doesn’t know. Give each pair a cost and use linearSumAssignment, or a value and use maximumWeightMatching. For a graph that isn’t bipartite, maximumMatching() uses Edmonds’ blossom algorithm.

In SwiftThe hiring above, in Grafluent

import AdjacencyListModule
import BipartiteGraphs
import GraphProtocols
import MatchingModule

let applicants = ["Ana", "Ben", "Cy", "Dee", "Eli"]
let jobs = ["Barista", "Cashier", "Driver", "Florist", "Gardener"]
let canDo = [
    ("Ana", "Barista"),
    ("Ana", "Cashier"),
    ("Ben", "Barista"),
    ("Cy", "Cashier"),
    ("Cy", "Driver"),
    ("Cy", "Florist"),
    ("Dee", "Driver"),
    ("Eli", "Driver"),
]

let skills = UndirectedAdjacencyList<String> {
    for name in applicants + jobs { name }
    for (applicant, job) in canDo { UndirectedEdge(applicant, job) }
}
let sides = skills.bipartition(left: applicants)!
let hires = skills.maximumBipartiteMatching(bipartition: sides)
let pairs = hires.edges.map { skills.edges[$0] }  // 4 pairs: Ana–Cashier, Ben–Barista, Cy–Florist, Dee–Driver

// `hire` is the code above; run it as the applicants arrive one at a time.
let rounds = (1 ... applicants.count).map { arrived in
    let present = Array(applicants.prefix(arrived))
    return hire(applicants: present, jobs: jobs, canDo: canDo.filter { present.contains($0.0) })
}

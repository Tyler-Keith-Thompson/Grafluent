import GraphProtocols
import ShortestPaths

// cost is −1000 × ln(rate), rounded: adding costs multiplies rates
let quotes: [(trade: DirectedEdge<String>, rate: Double, cost: Int)] = [
    (DirectedEdge(from: "USD", to: "EUR"), 0.9, 105),
    (DirectedEdge(from: "EUR", to: "USD"), 1.089, -85),
    (DirectedEdge(from: "USD", to: "GBP"), 0.7734, 257),
    (DirectedEdge(from: "GBP", to: "USD"), 1.29, -255),
    (DirectedEdge(from: "EUR", to: "GBP"), 0.865, 145),
    (DirectedEdge(from: "GBP", to: "EUR"), 1.152, -141),
    (DirectedEdge(from: "USD", to: "JPY"), 147.8, -4996),
    (DirectedEdge(from: "JPY", to: "USD"), 0.006633, 5016),
    (DirectedEdge(from: "EUR", to: "CHF"), 0.9723, 28),
    (DirectedEdge(from: "CHF", to: "EUR"), 1.008, -8),
    (DirectedEdge(from: "CHF", to: "JPY"), 165.5, -5109),
    (DirectedEdge(from: "JPY", to: "CHF"), 0.005922, 5129),
]

let market = AdjacencyList<String> {
    for quote in quotes { quote.trade }
}
let cost = Dictionary(uniqueKeysWithValues: quotes.map { ($0.trade, $0.cost) })

let events = Array(market.lazy.bellmanFord(from: "USD") { cost[market.edges[$0]]! })  // 43 events
let cycle: [String]? = switch events.last {
case .negativeCycle(let loop)?: loop.vertices
default: nil
}
let tradeRound = cycle ?? []  // ["USD", "EUR", "GBP"]

The ideaRelax every edge, again and again

Trading along a chain multiplies the rates, and the best chain has the largest product. Taking logarithms turns products into sums: give each trade the cost −ln(rate), and the best rate becomes the cheapest path. A rate above 1 has a negative cost, so Dijkstra’s algorithm can’t be used: its proof needs every edge to cost at least nothing.

Bellman–Ford doesn’t rely on that. It keeps a best cost for every vertex and, round after round, checks each edge out of every vertex that improved last round: if going through that edge is cheaper than the target’s best so far, lower it, called relaxing the edge. After round k, every path of up to k edges has been tried, and a shortest path visits each vertex at most once, so n − 1 rounds always suffice. If anything still improves in round n, some loop has a negative total and keeps paying: a negative cycle, here an arbitrage. lazy.bellmanFord(from:weight:) reports each round, each edge and, at the end, the cycle itself.

Where it breaksSlow, and real markets

Each round can touch every edge, so the worst case is O(nm), far slower than Dijkstra. Grafluent only rescans vertices that changed, which helps a great deal in practice; with no negative weights, use Dijkstra, and on a graph without cycles, the topological-order method takes one pass. To find shortest paths between every pair with some negative weights, Johnson’s algorithm runs Bellman–Ford once to reweight the edges and then Dijkstra from each vertex.

Real arbitrage loops are tiny and gone in moments, and trading fees usually eat them; the costs here are rounded to whole numbers, which works only because this market’s loop is comfortably above the rounding.

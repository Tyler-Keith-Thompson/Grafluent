Hypergraphs

A committee has five members. Which single edge of a graph could say that they meet as a group?

What it’s forLinks that join more than two things

An edge joins two vertices. A hyperedge joins any number of them at once: the members of a committee, the authors of a paper, the ingredients of a recipe, the stops of a bus route. A graph can only hint at such a group with pairs. A hypergraph keeps the group itself.

Reach for one when the group is the fact: who was in the room together, which items were bought in one basket, which proteins form one complex. You can always flatten it to a graph later, and the page shows what that loses.

The incidence graph, with a vertex for every committee, is the hypergraph in disguise and loses nothing; the clique expansion is handy and lossy.

The ideaA hyperedge is a set of vertices

UndirectedIncidenceList stores a hypergraph as rows: for each hyperedge its members, and for each vertex the hyperedges it is in. A hyperedge may hold one vertex, or none, and two hyperedges may hold the same members, since two committees can share a roster. size(ofHyperedgeAt:) is a hyperedge’s number of members, degree(of:) is the number of hyperedges a vertex is in, and the rank is the largest size.

Two vertices are neighbours when some hyperedge holds both, and the hypergraph is connected when every vertex can reach every other through shared hyperedges. neighbors(of:) and connectedComponents() answer those. cliqueExpansion() is the graph with a pair for every two members of a hyperedge, which the lab draws in its second mode. incidenceGraphView is the bipartite graph of memberships, drawn in the first.

Where it breaksMost algorithms want pairs

Shortest paths, centrality and community detection are defined on graphs. To run them you flatten: the clique expansion when pairs are what matter, the incidence graph when the groups must survive as vertices. A committee of fifty becomes 1,225 pairs in the expansion, so large hyperedges make it big. Directed hypergraphs, where a hyperedge has a tail set and a head set, as in a chemical reaction, are a separate type with their own reachability.

In SwiftThe council, in Grafluent

import Hypergraphs

let committees: [[String]] = [
    ["Ann", "Bert", "Cleo"],                 // budget
    ["Cleo", "Dev", "Ezra", "Fay"],          // hiring
    ["Ann", "Fay"],                          // audit
    ["Gus", "Hana", "Ivo"],                  // social
    ["Bert", "Dev", "Gus"],                  // safety
    ["Jude"],                                // archive, one person
]

let council = UndirectedIncidenceList(hyperedges: committees)

let sizes = council.hyperedges.indices.map { council.size(ofHyperedgeAt: $0) }  // [3, 4, 2, 3, 3, 1]
let busiest = council.vertices.map { council.degree(of: $0) }  // [2, 2, 2, 2, 1, 2, 2, 1, 1, 1]
let colleagues = council.neighbors(of: "Cleo")  // ["Ann", "Bert", "Dev", "Ezra", "Fay"]
let groups = council.connectedComponents()  // [["Ann", "Bert", "Cleo", "Dev", "Ezra", "Fay", "Gus", "Hana", "Ivo"], ["Jude"]]
let largest = council.rank  // 4

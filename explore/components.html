Connected components

Say itkoh-suh-RAH-joo/koːsəˈɾaːdʒu/

Which parts of a graph can reach each other?

What it’s forWhich parts hang together

Components split a graph into groups that can reach each other. Reach for them to find the separate pieces of a network, to check that a road map has no stranded towns, or to find the groups of web pages that all link round to each other.

Example: islands joined by bridges, for the undirected case. Then one-way streets, for the directed case.

UndirectedIslands and two-way bridges

Click a bridge to close it, or a dashed one to open it. Islands of the same colour are in the same component.

2 connected components

You can walk between any two islands of the same colour, and never between colours.

{Gull, Pine, Fern, Harbor, Mill, Reef}{Rock, Cove}
a new search startsit reaches another island

In SwiftThe islands above, in Grafluent

import AdjacencyListModule
import Connectivity
import GraphProtocols
import Traversal

let names = ["Gull", "Pine", "Fern", "Harbor", "Mill", "Reef", "Rock", "Cove"]
let bridges = [
    ("Gull", "Pine"),
    ("Pine", "Fern"),
    ("Gull", "Fern"),
    ("Fern", "Harbor"),
    ("Harbor", "Mill"),
    ("Mill", "Reef"),
    ("Rock", "Cove"),
]

let islands = UndirectedAdjacencyList<String> {
    for island in names { island }
    for (a, b) in bridges { UndirectedEdge(a, b) }
}
let groups = islands.connectedComponents()  // 2: {Gull, Pine, Fern, Harbor, Mill, Reef} {Rock, Cove}

// The same groups, one search at a time: each search reaches exactly one group.
var reached = Set<String>()
var searches: [[BreadthFirstSearchEvent<String>]] = []
for island in names where !reached.contains(island) {
    let search = Array(islands.directedView.lazy.breadthFirstSearch(from: island))
    for case .discover(let found) in search { reached.insert(found) }
    searches.append(search)
}

Click a street to turn it around. Corners of the same colour are in the same neighbourhood. Grey dashed streets run between neighbourhoods.

4 strongly connected components

Inside a colour you can drive from any corner to any other and back. Between colours, traffic only flows one way.

In SwiftThe streets above, in Grafluent

import AdjacencyListModule
import Connectivity
import GraphProtocols
import Traversal

let corners = ["Park", "School", "Market", "Mill", "Dock", "Bakery", "Hill", "Square", "Church"]
let oneWay = [
    ("Park", "School"),
    ("School", "Market"),
    ("Market", "Park"),
    ("Market", "Mill"),
    ("Mill", "Dock"),
    ("Dock", "Mill"),
    ("Dock", "Bakery"),
    ("Hill", "Square"),
    ("Square", "Church"),
    ("Church", "Hill"),
    ("Church", "Mill"),
]

let streets = AdjacencyList<String> {
    for corner in corners { corner }
    for (from, to) in oneWay { DirectedEdge(from: from, to: to) }
}
let neighbourhoods = streets.stronglyConnectedComponents()  // 4: {Bakery} {Mill, Dock} {Park, School, Market} {Hill, Square, Church}
let condensation = streets.condensation()
let links = condensation.graph.edgeCount  // 3
let events = Array(streets.lazy.depthFirstSearch())  // 29 events

The ideaWho can get to whom

With two-way bridges, two islands are in the same component if you can walk from one to the other. One search from an island finds its whole component.

With one-way streets the rule is stricter. A strongly connected component is a neighbourhood where you can get from any corner to any other and back again. Tarjan’s and Kosaraju’s algorithms find them all. Grafluent uses Tarjan’s, which needs one depth-first search, in Pearce’s low-memory form.

Shrink each strongly connected component to a dot. What’s left is the condensation, and it has no cycles. It shows the order in which traffic can flow between neighbourhoods.

All of them run in time in proportion to the graph. In the table, n is the number of vertices and m the number of edges.

Where it breaksWhether, not how well

Components only say whether a route exists. To know how good a route is, use a shortest-path search such as Dijkstra’s algorithm.

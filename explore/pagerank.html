PageRank

Which pages on a web matter most?

Example: six web pages linking to each other. Add a link and see the ranks shift.

Bigger circle, higher rank. Click one page and then another to add a link; click an arrow to remove it.

Bars: PageRank, which adds up to 1. Black ticks: the share of the surfer’s 0 visits so far on each page. The longer the surfer goes, the closer the ticks come to the bars.

At 0.85 the surfer follows a link 85% of the time and jumps to a random page otherwise. At 0 every page scores the same.

follow a linkjump to a random page

A random surfer, step by step: Grafluent’s randomWalk follows the links, and the surfer jumps whenever the damping coin says stop.

In SwiftThe web above, in Grafluent

import AdjacencyListModule
import Centrality
import GraphProtocols
import Traversal

let pages = ["Home", "Blog", "Recipes", "About", "Shop", "Forum"]
let links = [
    ("Home", "Blog"),
    ("Home", "Shop"),
    ("Home", "About"),
    ("Blog", "Recipes"),
    ("Blog", "Home"),
    ("Recipes", "Blog"),
    ("Recipes", "Home"),
    ("About", "Home"),
    ("Shop", "Home"),
    ("Shop", "Recipes"),
    ("Forum", "Recipes"),
    ("Forum", "Blog"),
]
let damping = 0.85

let web = AdjacencyList<String> {
    for page in pages { page }
    for (from, to) in links { DirectedEdge(from: from, to: to) }
}
let ranks = try web.pageRank(dampingFactor: damping, maxIterations: 1000)
let scores = pages.map { ranks.score(of: $0) }  // [0.345, 0.208, 0.176, 0.123, 0.123, 0.025]

let seed: UInt64 = 1

let web = AdjacencyList<String> {
    for page in pages { page }
    for (from, to) in links { DirectedEdge(from: from, to: to) }
}
// A surfer jumps to a random page, follows links while a coin with odds `damping` says
// keep going, then jumps again.
var generator = SplitMix64(seed: seed)
var visits: [(page: String, jumped: Bool)] = []
while visits.count < 200 {
    var clicks = 0
    while clicks < 50, Double.random(in: 0 ..< 1, using: &generator) < damping { clicks += 1 }
    // One draw of 64 bits picks the page, so a seed gives the same surfer on every platform.
    let jump = pages[Int(generator.next() % UInt64(pages.count))]
    let walk = web.randomWalk(from: jump, length: clicks, using: &generator)
    visits += walk.enumerated().map { (page: $0.element, jumped: $0.offset == 0) }
}

The ideaA bored random surfer

Imagine someone browsing at random: they follow a link, and every so often they get bored and jump to any page at all. Over a long session, the share of time they spend on each page is its rank. A link from an important page is worth more than one from an obscure page. The damping factor sets how often they keep clicking instead of jumping, usually 85%.

Grafluent computes it by power iteration: start everyone equal, pass each page’s rank along its links, and repeat until nothing moves by more than the tolerance. A page with no links out shares its rank with every page.

Where it breaksPages that hoard rank

A tight cluster of pages that only link to each other can soak up rank. The random jump keeps that in check, and turning the damping all the way up shows what happens without it: the surfer can get stuck going round, and the scores may never settle.

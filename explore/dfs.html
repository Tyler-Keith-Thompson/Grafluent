Depth-first search

Starting from one vertex, how do you visit everything you can reach, one corridor at a time?

Example: a small office building. Rooms are vertices, doors are edges, and you start at reception. The doors are one-way, like fire doors that only open from one side, so the graph is directed.

In SwiftThe building above, in Grafluent

import AdjacencyListModule
import GraphProtocols
import Traversal

let doors = [
    DirectedEdge(from: "Reception", to: "Kitchen"),
    DirectedEdge(from: "Reception", to: "Meeting room"),
    DirectedEdge(from: "Kitchen", to: "Archive"),
    DirectedEdge(from: "Kitchen", to: "Server room"),
    DirectedEdge(from: "Archive", to: "Reception"),
    DirectedEdge(from: "Archive", to: "Server room"),
    DirectedEdge(from: "Meeting room", to: "Archive"),
    DirectedEdge(from: "Meeting room", to: "Lounge"),
    DirectedEdge(from: "Lounge", to: "Print room"),
    DirectedEdge(from: "Print room", to: "Server room"),
]

let office = AdjacencyList<String> {
    for door in doors { door }
}

let start = "Reception"

let events = Array(office.lazy.depthFirstSearch(from: start))  // 24 events: discover(Reception), treeEdge(Reception→Kitchen), …

The ideaAs deep as it goes, then back up

Depth-first follows one corridor as far as it goes, then backs up to the last junction and tries the next way. It is the natural way to explore a maze. It keeps the rooms it has entered but not yet finished in a stack: the newest is always next, which is the path from reception to where you stand.

Its order of “entered” and “finished” reveals a graph’s structure. Each edge it meets is coloured by what it means: a new room (a tree edge), a door back to a room still being explored (a back edge, the sign of a cycle), a door to a room already finished further down the same corridor (a forward edge), and a door into a branch already finished (a cross edge). Topological sort and strongly connected components are both built on these times.

Where it breaksDeep is not near

The first route depth-first finds to a room can be a long way round. For the route with the fewest doors, use breadth-first search; once doors have different lengths, Dijkstra’s algorithm.

Got a graph of your own? Paste it, see it, and search it.

DOT is the easiest to read and write. graph6 is the most compact. GraphML carries the most.

The ideaRead, draw, run

Each format has an initializer on any graph that can be built up: UndirectedAdjacencyList<String>(dot:), (graphML:), (graph6:vertex:) and (edgeList:). They read bytes, so a file’s contents go straight in. Attributes come out through closures as the reader meets them, keyed by the new edge’s position. Nothing about the text is kept once the graph is built.

The drawing is a force-directed layout from a fixed seed, so the same text always draws the same way. Breadth-first search and Dijkstra are the lazy, step-by-step forms the BFS and Dijkstra pages use. The components are coloured as on the components page.

Where it breaksErrors, and what readers leave out

A reader that can’t make sense of the text throws a ParseError. It holds the kind of error and the line and column of the character at fault, counted in Unicode scalars, so an editor can jump straight there. Errors are typed, so a catch gets a ParseError and never some other error.

Formats carry more than a graph, such as DOT’s colours and shapes, GraphML’s typed keys, and an edge list’s extra columns. The readers hand every attribute to the closures and keep none themselves. So anything this page doesn’t ask for, such as positions written in the file, is read and dropped. graph6 has no names at all. Its vertices are numbers, which the vertex: closure here turns into text.

In SwiftWhat the page runs, in Grafluent

import AdjacencyListModule
import Connectivity
import GraphDrawing
import GraphFormats
import GraphProtocols
import RandomGraphs
import ShortestPaths
import Traversal

let text = "graph town {\n  Home -- Bakery [weight=4];\n  Home -- Park …"
let start = "Home"

var weights: [Int: Int] = [:]
let graph = try UndirectedAdjacencyList<String>(dot: Array(text.utf8), edgeAttribute: { edge, key, value in
    if key == "weight", let w = Int(value.description) { weights[edge] = w }
})

let centre = "\u{2063}"  // an invisible name, for the undrawn centre
let tied = UndirectedAdjacencyList<String> {
    for v in graph.vertices where v != centre { UndirectedEdge(v, centre) }
    for edge in graph.edges { edge }
}
var placer = Xoshiro256StarStar(seed: 1)
let drawing = tied.fruchtermanReingoldLayout(iterations: 150, weight: { tied.edges[$0].v == centre ? 0.15 : 1 }, using: &placer)

let events = Array(graph.lazy.edgeBreadthFirstSearch(from: start))  // 23 events

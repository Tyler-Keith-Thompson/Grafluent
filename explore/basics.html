Graph basics

What exactly is a graph, and which kinds will you meet on these pages?

A graph has two parts. Vertices are the objects you care about: cities, people, web pages, tasks in a build. Edges are the relationships between pairs of them: a road, a friendship, a link, a dependency. Graph theory calls the objects vertices; many libraries and papers call them nodes. They mean the same thing.

Click a vertex to pick it.

Vertex B

B’s neighbours are A, C, D: 3 edges touch it, so its degree is 3.

In SwiftThe graph above, in Grafluent

import AdjacencyListModule
import GraphProtocols

let pairs = [("A", "B"), ("A", "C"), ("B", "C"), ("B", "D"), ("C", "D"), ("D", "E")]
let picked = "B"

let graph = UndirectedAdjacencyList<String> {
    for (u, v) in pairs { UndirectedEdge(u, v) }
}
let neighbors = Array(graph.neighbors(of: picked))  // ["A", "C", "D"]
let degree = graph.degree(of: picked)  // 3

DirectionUndirected and directed

In an undirected graph an edge works both ways, like a friendship or a two-way street. In a directed graph each edge has a start and an end, drawn as an arrow, like a one-way street, a link from one page to another, or “compile before test”. Grafluent keeps the two as separate kinds of graph, so an algorithm that only makes sense for one can’t be handed the other by mistake.

WeightsNumbers on the edges

Often an edge carries a number: minutes to walk a street, the cost of a cable, how much a pipe can carry. That number is the edge’s weight. A graph with them is a weighted graph. Grafluent never stores weights inside the graph itself. You keep them wherever suits you and pass the algorithm a way to look each one up, so the same graph can be measured in minutes on one page and in kilometres on the next.

Walks, paths and cyclesRoutes, and routes that come back

A walk is any route you can trace along edges, one after another. It may pass the same vertex or edge more than once. A path is a walk that never visits a vertex twice. A cycle is a walk that ends where it started and repeats no other vertex on the way.

Cycles matter a lot. A road network is full of them, while tasks with dependencies must have none, or no order could ever finish them. Grafluent has a type for each: Walk, Path and Cycle. An algorithm that returns a route returns the type that says exactly what it guarantees.

Two more you’ll seeSelf-loops and parallel edges

A self-loop is an edge from a vertex to itself, like a road that leaves a town and comes back. Parallel edges are two or more edges between the same pair, like a highway and a back road between the same two towns. A graph that allows them is called a multigraph. Grafluent tells parallel edges apart by their position in the graph, so each can have its own weight.

Try them in the graph near the top of the page: pick a vertex to see its neighbours, switch between undirected and directed, and show the weights.

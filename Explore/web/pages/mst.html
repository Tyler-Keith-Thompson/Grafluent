Minimum spanning trees

What’s the cheapest set of cables that connects every house?

What it’s forThe cheapest network that reaches everyone

A minimum spanning tree joins every place using the cheapest set of links. A tree is a connected network with no cycles, so n places need n − 1 links, and “spanning” means it reaches every place. It has no cycles, because a cycle would mean one link could go without cutting anyone off. Reach for it to plan cables, pipes or roads, and as a first step in clustering, grouping similar items, and in tour planning.

Compared withThree ways to the same tree

All three find a tree of the same total cost. They differ in the order they lay cables. In the table, n is the number of houses and m the number of possible cables, and log n grows very slowly.

Example: six houses, and the cost of laying cable between each pair that can be joined.

The ideaTwo ways to the same cheapest network

Kruskal sorts every possible cable from cheapest to dearest. It lays each one, unless the cable would only join two houses that are already connected. Prim grows a single network outward from one house. It always adds the cheapest cable that reaches a house not yet connected. The routes differ, but the total cost is the same.

Either way the result is a spanning tree. Every house is connected, and there are no cycles. So six houses need exactly five cables.

The cheapest network is one of many. spanningForests(weight:) lists every spanning tree from the cheapest up, so the runners-up are there when the cheapest cable cannot be laid; the code at the end shows the three cheapest totals. A forest is several trees, and on a connected network it is one tree, which is why the name says forests.

Kruskal tracks who is already connected with a union–find structure. It answers “same group?” almost at once. Prim keeps a queue of the houses waiting to join, each with the cheapest price on offer so far. Dijkstra keeps its frontier the same way.

Where it breaksCheapest isn’t shortest

The cheapest network isn’t the one with the shortest routes. The trip between two houses can be long and winding. If travel time matters, that is a shortest-path problem.

Here a direct Dev–Eli cable would cost 5, and it isn’t in the network. A signal from Dev to Eli goes through Ada and Ben, over three cables instead of one.

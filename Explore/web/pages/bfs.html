Breadth-first search

Starting from one vertex, how do you visit everything you can reach, nearest first?

Example: news spreading through nine friends. Each friend is a vertex; an arrow from one to another means the first messages the second, so the graph is directed. Ana hears first. This page uses the words from Graph basics: vertex, edge, directed.

In SwiftThe friends above, in Grafluent







  
The ideaRing by ring

  
Breadth-first explores in rings. Visit every vertex one edge away, then every vertex two edges away, and so on. It keeps the vertices it has discovered but not yet finished in a queue: the oldest is always next, so nobody two rings out is reached before everybody one ring out.

  
Because it goes ring by ring, the first time it reaches a vertex is along a route with the fewest edges. The blue tree edges record those routes: follow them back from anyone to the start. The other edges, non-tree edges, lead to someone already reached.


  
Where it breaksEdges are not distances

  
Breadth-first counts edges, not distance. Once edges have different lengths, like corridors or roads, fewest edges is no longer shortest, and you want Dijkstra’s algorithm. To explore one route as deep as it goes first, use depth-first search.

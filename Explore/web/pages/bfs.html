Breadth-first search

Starting from one vertex, how do you visit everything you can reach, nearest first?

Example: news spreading through nine friends. An arrow from one friend to another means the first messages the second, so the graph is directed. Ana hears first. This page uses the words from Graph basics, such as vertex, edge and directed.

When to use itFewest steps, nearest first

Breadth-first search finds everything you can reach from a start. It also finds the route to each place with the fewest steps. Reach for it when every step costs the same, as with hops in a network or moves in a puzzle. It is also the way to sort places into rings by how far away they are.

The ideaRing by ring

Breadth-first search explores in rings. It visits every vertex one edge away, then every vertex two edges away, and so on. It keeps a queue of the vertices it has found but not yet finished. The oldest one is always next. So nobody two rings out is reached before everybody one ring out.

Because it goes ring by ring, it first reaches each vertex by a route with the fewest edges. The blue tree edges record those routes. Follow them back from anyone to reach the start. The other edges are non-tree edges. Each one leads to someone already reached.

Where it breaksEdges are not distances

Breadth-first search counts edges. When edges have different lengths, like roads, the route with the fewest edges may not be the shortest. Then you want Dijkstra’s algorithm. To follow one route as deep as it goes before trying the next, use depth-first search.

Girvan–Newman

If you keep cutting the link that the most shortest paths cross, what groups are left?

Example: twelve friends from a band, a climbing gym and a book club, and a line between each pair who hang out. A few friendships cross between the groups.

In SwiftThe friends above, in Grafluent







  
The ideaLinks between groups carry the traffic

  
Inside a close group there are many ways between any two people, so the shortest paths spread over many links. Between groups there are only a few links, and every shortest path from one group to another has to use one of them. So those links have the highest edge betweenness.

  
Girvan and Newman’s method takes out the link with the highest betweenness, then recomputes every score, and repeats. Recomputing matters: once one link between two groups is gone, the paths it carried move to the others, which become the busiest next. Each time the network falls into more pieces, the pieces are a finer partition. Run to the end and every person is alone; the result is a whole hierarchy of splits, coarsest first.

  
Which level is the answer? A common choice is the one with the highest modularity: the share of links inside groups, minus the share you’d expect if links were placed at random with the same degrees. girvanNewmanCommunities() is a lazy sequence of the partitions, so you can stop at the first with as many groups as you want, or take the best by modularity(of:).


  
Where it breaksSlow, and when to use something else

  
Every removal recomputes betweenness for the piece it came from, which costs a search from every person in it. That is fine for a few hundred people and far too slow for a large network: the whole sequence is O(m² n). For large networks, Louvain or Leiden find high-modularity groups in a few passes. Girvan–Newman is still worth knowing when the hierarchy itself is wanted, or when the network is small enough that its clear reasoning is worth the time.

  
It also only ever cuts. A person who belongs to two groups ends up in one of them, and a network with no clear groups still gets split, all the way down, so a high modularity is worth checking before trusting the groups.

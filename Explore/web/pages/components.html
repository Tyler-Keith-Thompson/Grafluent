The ideaWho can get to whom

  
With two-way bridges, two islands are in the same component if you can walk from one to the other. With one-way streets it is stricter: a strongly connected component is a neighbourhood where you can get from any corner to any other and back again. Tarjan’s and Kosaraju’s algorithms find them all in a single pass or two. Grafluent uses Tarjan’s, one depth-first search, in Pearce’s low-memory form.

  
Shrink each strongly connected component to a dot and what’s left, the condensation, has no cycles, which tells you the order traffic can flow between neighbourhoods.


  
Where it breaksWhether, not how well

  
Components only say whether a route exists. To know how good it is, use a shortest-path page such as Dijkstra’s algorithm.

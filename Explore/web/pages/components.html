Connected components

Say itkoh-suh-RAH-joo/koːsəˈɾaːdʒu/

Which parts of a graph can reach each other?

What it’s forWhich parts hang together

Components split a graph into groups that can reach each other. Reach for them to find the separate pieces of a network, to check that a road map has no stranded towns, or to find the groups of web pages that all link round to each other.

Example: islands joined by bridges, for the undirected case. Then one-way streets, for the directed case.

The ideaWho can get to whom

  
With two-way bridges, two islands are in the same component if you can walk from one to the other. One search from an island finds its whole component.

  
With one-way streets the rule is stricter. A strongly connected component is a neighbourhood where you can get from any corner to any other and back again. Tarjan’s and Kosaraju’s algorithms find them all. Grafluent uses Tarjan’s, which needs one depth-first search, in Pearce’s low-memory form.

  
Shrink each strongly connected component to a dot. What’s left is the condensation, and it has no cycles. It shows the order in which traffic can flow between neighbourhoods.

Where it breaksWhether, not how well

  
Components only say whether a route exists. To know how good a route is, use a shortest-path search such as Dijkstra’s algorithm.

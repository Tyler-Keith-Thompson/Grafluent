Paste a graph

Got a graph of your own? Paste it, see it, and search it.

Example: a small town, written in DOT. Change it, pick another format for an example in that one, or paste your own. The page takes up to 200 vertices. A DOT digraph, a GraphML graph with edgedefault="directed" or a digraph6 line is read as directed, with arrows; everything else as undirected. When an edge has a weight attribute that is a whole number, Dijkstra uses it. Other edges weigh 1.

Compared withWhich format to use

DOT is the easiest to read and write. graph6 is the most compact. GraphML carries the most.

The ideaRead, draw, run

Each format has an initializer on any graph that can be built up: UndirectedAdjacencyList<String>(dot:), (graphML:), (graph6:vertex:) and (edgeList:), and the same on AdjacencyList<String> for a directed text, with (digraph6:vertex:); a text whose kind does not match the graph it is read into throws, and the page then reads it as the other kind. They read bytes, so a file’s contents go straight in. Attributes come out through closures as the reader meets them, keyed by the new edge’s position. Nothing about the text is kept once the graph is built.

The drawing is a force-directed layout from a fixed seed, so the same text always draws the same way. Breadth-first search and Dijkstra are the lazy, step-by-step forms the BFS and Dijkstra pages use. The components are coloured as on the components page.

Where it breaksErrors, and what readers leave out

A reader that can’t make sense of the text throws a ParseError. It holds the kind of error and the line and column of the character at fault, counted in Unicode scalars, so an editor can jump straight there. Errors are typed, so a catch gets a ParseError and never some other error.

Formats carry more than a graph, such as DOT’s colours and shapes, GraphML’s typed keys, and an edge list’s extra columns. The readers hand every attribute to the closures and keep none themselves. So anything this page doesn’t ask for, such as positions written in the file, is read and dropped. graph6 has no names at all. Its vertices are numbers, which the vertex: closure here turns into text.

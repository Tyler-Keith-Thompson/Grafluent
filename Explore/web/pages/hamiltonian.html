Hamiltonian cycles

Can you visit every place exactly once and end where you began?

Example: the icosian game, which William Rowan Hamilton sold as a puzzle in 1857. Twenty places sit at the corners of a dodecahedron, flattened here onto the page, each joined to three others. The goal is a round trip through all twenty, a Hamiltonian cycle.

The ideaEvery vertex once, not every edge

  
An Euler tour uses every road once, and there is a quick test for whether one exists: every place has an even number of roads. A Hamiltonian cycle uses every place once, and no such test is known. The general question is NP-complete: as far as anyone knows, answering it for every graph takes time that grows exponentially with its size.

  
So the search tries. Grafluent’s hamiltonianCycle() grows a route one place at a time, always to the first neighbour not yet visited, and backs up when it gets stuck, as the second lab does. It also stops early in a branch that can’t work: when some place left over can no longer be reached, or has too few unvisited neighbours to be passed through. That pruning doesn’t change which cycle comes out first, only how long it takes. hamiltonianPath(from:to:) asks the same of a route with fixed ends, which is how the first lab checks whether yours can still be finished: what is left must have a path from your current place, through everything unvisited, back to the start.


  
Where it breaksSmall graphs, or special ones

  
The dodecahedron is solved in a moment because it is small and every place has only three roads. Each added place multiplies the routes to try, and a few hundred places can be out of reach. For larger graphs there are useful sufficient conditions: Dirac’s theorem says a graph of n ≥ 3 places, each joined to at least half of the others, always has a Hamiltonian cycle. But they only ever say yes; a graph that fails them may still have one.

  
Proving that a graph has no Hamiltonian cycle is harder still: the search has to rule out every route. The Petersen graph, ten places with three roads each, is the classic example, and hamiltonianCycle() answers nil for it only after exhausting the search. Ask for the shortest such cycle with distances on the roads, and it becomes the travelling salesman problem.
